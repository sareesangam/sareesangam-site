Drop your product photos directly into this folder (jpg, jpeg, png, webp, or gif).

- File name becomes the caption shown under the photo — e.g. "red-silk-saree.jpg" shows as "Red Silk Saree".
- No need to edit any code or list files anywhere else — the home page automatically shows every image in this folder.
- After adding/removing images here, commit and push to GitHub (see DEPLOY.md) and the live site updates within a minute or two.
