Drop Anchee product photos in this folder (jpg, jpeg, png, webp, gif).

File name format:  name-of-product_PRICE_SIZES.jpg
  e.g.  new-khadi-block-print-kurti_1299_S-M-L-XL.jpg

  - name-of-product : becomes the title ("Khadi Block Print Kurti").
  - PRICE           : optional, rupees (Rs. 1,299).
  - SIZES           : optional, joined by dashes: XS S M L XL XXL 3XL FREE (e.g. S-M-L-XL).
                      Shown on the card and used by the Size filter.
  - Start the name with "new-" to show a NEW badge.
  - Put a category keyword in the name: mulcotton, khadi, short, tunic.

Commit and push to GitHub; the Anchee page updates automatically.
